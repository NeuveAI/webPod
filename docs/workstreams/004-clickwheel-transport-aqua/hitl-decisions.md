- Live playback makes previous/next global transport controls; without live playback they page lists.
- The honest center cycle begins at standard Now Playing, then scrub, full artwork, queue, and only genuinely implemented rating/lyrics states. Wheel rotation on standard Now Playing controls volume; volume is not a labeled mode. Non-functional rate/love/shuffle/repeat states and every instructional mode slab are removed.
- Queue control means provider-backed queue browsing in this slice, not destructive queue reordering.
- Navigating to root pauses audible playback but preserves the current provider item/queue context; subsequent Play/Pause returns to Now Playing and toggles the real provider.

Escalate only if the implementation cannot satisfy these without changing the provider contract or if authenticated Apple behavior contradicts the deterministic contract.
