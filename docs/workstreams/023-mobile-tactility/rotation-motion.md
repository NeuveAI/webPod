## Geometry readiness integration

Supervisor expanded this lane to preserve entry while geometry owner moves complete shell construction before scene publication. Added an inner Suspense boundary around the entire canvas scene, including warmup. Pinned Fiber's outer Suspense uses Block to suspend its DOM Canvas parent; the inner boundary keeps the DOM canvas mounted while preventing a partial scene/warmup commit. Geometry owner must resolve its bounded worker/cooperative preparation before this scene can mount; no post-upload shell swap is introduced by motion.

The prior10s reveal safety timeout unconditionally completed entry, even if valid geometry was still pending. It now exposes no-canvas/explicitly-failed graphics UI while retaining the readiness observer for a preparing canvas. A failure reported after timeout still completes the fallback. Actual warm-ready cancels the fallback timer and starts the same existing minimum-hold/curve. Geometry worker deadlines/fallback belong to the geometry owner; this reveal code does not invent another job timeout or declare slow work failed. No animation trajectory, step clamp or authored duration changes.

Retained entry-readiness.ts/json executes the real reveal owner under deterministic scheduling: pending beyond safety timer stays warming; later real-ready starts entry; all per-frame orientation values match the original curve after the existing store clamp; final pose settles; no-canvas, immediate failed, late failed paths complete fallback; no RAF survives disposal. Signed zero at rest uses the existing store's equality convention (===), rather than introducing a new normalization. This is a temporary experiment, not a new unit test or browser timing claim.

The warmup owner now has its own10s compile deadline, started only after the complete Suspense scene commits. A stalled driver publishes `failed`; late completion is ignored, and success, rejection and unmount clear the deadline. This prevents an indefinitely pending graphics driver from defeating the revised reveal fallback while still never revealing partial geometry. `warmup-lifecycle.ts/json` exercises the actual component with deterministic hooks: timeout, late completion, unmount, rejected compile, unchanged three warm frames, and no residual application scheduling all pass. Three internal compile polling has no cancellation API; suppressing publication does not cancel its internal driver polling.
