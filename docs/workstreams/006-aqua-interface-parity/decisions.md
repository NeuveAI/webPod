- The nine supplied HEIC photos are geometric authority. All were converted with sips under evidence/references and visually inspected along with both attached PNGs. - The supplied photos favor title-only track rows, so album/playlist tracks omit redundant track number and artist columns. Provider metadata remains in the model and Now Playing. Now Playing uses real queueRead position/count, 82px artwork, peer metadata, and existing progress/scrub/volume behavior. No queue count is invented if the provider cannot supply it.

- Review identified a real color transfer bug: pinned Three 0.185 WebGLTextures uploads HTMLTexture through RGBA8, bypassing hardware sRGB decoding. A scoped material hook applies Three's own EOTF once to that map sample. SRGBColorSpace stays correct; other device materials are unchanged. A regression checks the real shader and pinned upload invariant so an upstream sRGB-storage change requires review.
- The requested ~/code/agentic-context directory is absent. Read ~/code/agent-context/global.md and pinned dependency source, including Three's renderer and map_fragment, as available authoritative fallback. Used modern-web-guidance through bunx, repo law taking precedence over its npx example.
- Preserve existing experimental CanvasDrawElement capability requirements; no new proof/product route. Browser captures use installed Chrome with the existing flag and an explicit deterministic MusicKit seam. No live signing keys or account credentials were accessed.
