W2 — the constants that are rulings, gated against literals
===========================================================

D-050: a constant is gated only if falsifying it turns a test red.

The review demonstrated that this package contained both patterns. Its arc
geometry was genuinely gated — falsifying `arcDegPerDetent`, the dead zone or
either acceleration threshold turned 7 tests red — because those tests feed
literal degrees and assert literal detent counts. But `VISIBLE_ROWS` and
`ANNOUNCE_DEBOUNCE_MS` were asserted only through themselves, so replacing the
per-density page sizes with a flat 7 (the value the lead had ruled against) and
cutting the debounce from 350ms to 50ms both left 93 of 93 tests passing.

`gates.test.ts` closes that class: every value that is a decision rather than a
derivation is asserted against a literal transcribed from the source, with the
source cited.

⚑ It has since done the job it was built for. When D-063 ruled that
design-system §9.4 governs the wheel model over pm-spec §4.4, the constants it
gates went red immediately and precisely — the acceleration tiers, the
thresholds and the coast floor — rather than the change landing silently
against tests that computed both sides from the same symbol. The values are now
§9.4's, the rejected §4.4 figures are named in the assertions so a reader knows
each one settles a conflict, and `w2-d063-go-red.txt` plants every one of them
wrong twice.
