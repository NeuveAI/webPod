## Type escapes
```
$ grep -rnE ':\s*any\b|<any>|\bas any\b|\bany\[\]|Array<any>' packages/providers/src
exit=1

# the first form of this grep wrote `as any` with no word boundary and matched the word
# "anyone" in a doc comment. Kept on the record rather than quietly swapped: a prohibition
# grep that fires on prose is a grep whose next false positive gets waved through.
$ grep -rnE ': *any|<any>|as any|any\[\]' packages/providers/src
packages/providers/src/apple/matrix.ts:22: * What Apple Music can do, as far as anyone here has been able to establish.
exit=0

$ grep -rn '@ts-expect-error' packages/providers/src
packages/providers/src/identity.test.ts:93:    // @ts-expect-error a plain string must not satisfy LocalKey — §14.5
packages/providers/src/identity.test.ts:99:    // @ts-expect-error catalogId is a provider id and must not be a key — §14.5
packages/providers/src/identity.test.ts:105:    // @ts-expect-error libraryId is a provider id and must not be a key — §14.5
exit=0

$ grep -rn '@ts-ignore\|@ts-nocheck\|eslint-disable' packages/providers/src
exit=1

$ grep -rnE '[A-Za-z0-9_)\]]!\.' packages/providers/src
exit=1
```
Three `@ts-expect-error`, all in `identity.test.ts`, all load-bearing: they are the compile-time
proof that a bare string, a `catalogId` and a `libraryId` cannot occupy a `LocalKey` slot. If the
brand ever stops rejecting one, `tsc` fails on the now-unnecessary directive. The invariant is
recorded in `decisions/w1.md` §3, as the type-gate rules require.
No `any`, no `@ts-ignore`, no lint suppression, no non-null assertion anywhere in the package.
