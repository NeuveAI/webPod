# PLAYWORN approval collection

**Current review status:** on 2026-09-06 the user selected **Heavy Rotation** (“I vouch for heavy rotation”). It replaces the rejected Riff Ritual in PW-A05 and its device study. The [comparison board](../../design/playworn-riff-alternatives.html), Pencil frame e3jX6c, retains the alternative for reference. Design document: [stickers.pen](../../design/stickers.pen). Open only through Pencil; the file is encrypted.

Sixty original sticker designs, five per genre. Shared direction: warm ivory vinyl perimeter, satin finish, worn spot-colour ink, small catalogue marks. Listening stories are illustrative, not implemented earning rules.

User-requested refinements cover Sing It Back, Mixtape Kid, Deep Cut, Back Again, Demo Days, Room Tone, Echo Chamber and Crate Find. See [revision scope](revisions.md), [designer revision handover](revision-designer-handover.md), [brand revision handover](revision-brand-handover.md) and [targeted revision review](revisions-review.md). The linked previews include adopted corrections; original shared sheets remain intact.

The [second refinement round](revisions-round-2.md) unifies metal cream to #F3EBD7, outlines Full Volume, replaces Back Again with **Riff Ritual**, redesigns Mixtape Kid around a real cassette, and separates Beat Tape's cassette from its drum machine. Current source details are in the [metal handover](revision2-brand-handover.md), [cassette handover](revision2-designer-handover.md) and [round-two review](revisions-round-2-review.md). These supersede earlier descriptions of the affected stickers.

## Approval boundary

This is a collection-direction and artwork approval set. Successful metal artwork remains vector; most expanded designs are raster artwork in separately movable crop frames. The subsequent export delivery provides sixty individual transparent PNG bases and removes proof-liner backgrounds and presentation crop masks. See the [export audit](export-review.md) and [asset manifest](../../../assets/stickers/playworn/manifest.json) for exact files and limitations. Artwork acceptance precedes app implementation. No earning logic or sticker-placement functionality was implemented in this design task.

The [app implementation handover](app-sticker-handover.md) defines the separate shared laminate texture and reflective finish, with integration points in the current production renderer. The PNGs supply printed artwork only; runtime finish, placement and earning rules remain the next implementation task.

Exact motif names, node IDs, and source images: [designer handover](designer-handover.md), [brand expansion handover](brand-expansion-handover.md). Independent verification: [review](review.md).
