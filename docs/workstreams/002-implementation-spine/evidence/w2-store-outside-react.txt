W2 — the store is readable, writable and subscribable from OUTSIDE REACT
========================================================================

The property: device state lives in a Jotai `createStore()` and is reachable
through `store.get` / `store.set` / `store.sub` with NO React tree mounted.
Stage 3 registers WebMCP tools whose `execute` callbacks live outside the React
tree and must read and write the same state the UI renders. State held in a
component closure is unreachable from a tool handler.

`packages/state/src/store.test.ts` imports no React, renders nothing and mounts
no provider. It also asserts structurally that React is not even resolvable
from this package.
