# Worker implementation diary

Normal operation moves paper curl and the entire rear carry pipeline off the main thread. Rear grab peel, exterior constraints, free transport, depth lift, return path, landing blend, final collision constraints, normals, bounds and wear geometry publish as one completed pose. Source and target surfaces are cached in the carry worker. The rear chart's actual form is copied with geometry and rebound in the worker; losing that WeakMap binding would change wrapped edges.

The shared paper pool owns one module worker across devices, FIFO service between owners and one job per owner. There are at most 32 owners; excess surfaces take the exact cooperative recovery path. The scene enforces the existing two neighboring packet slots plus one liner. Carry owns one worker per active device, never per placed sticker. Visibility workers are transient and terminate after assembly preparation. No source rendering buffers are transferred: worker output owns newly copied arrays and main restores their attributes/bounds without normal recomputation. Geometry replaced in React is disposed after the replacement commit.

Each owner retains its last completed compatible geometry while a job runs and keeps one latest pending input. Completed progress within the same owner/epoch can publish monotonically, followed by the newest pending pose, avoiding starvation. Jotai computation epochs advance at interaction supersession/cancellation, reset and release-animation start. They flow through the production visual contract. Previous-epoch results are rejected; paper requests update in layout before browser worker events can run. Carry output includes its input snapshot and matching wear geometry. Initial carry borrows the already displayed source mesh until its first complete result.

Worker constructor failures, errors, message errors and timeouts terminate the worker and invoke the same generator math cooperatively, with an initial macrotask and a 4ms yield budget. Large vertex loops checkpoint every 128 iterations. Paper remains 96segments; no permanent approximate mesh was introduced. Standard Three allocations, buffer copies, normal/bounds routines and chart construction still execute as bounded library stages between checkpoints: this is not a hard 4ms preemption guarantee. DOM matrix reads, scene snapshot collection, React commit and GPU upload remain main-thread responsibilities. Recovery is off the initiating input stack and preserves exact output.

Hidden owners cancel worker/fallback execution and retain latest intent for visibility restoration. Disposal terminates ownership, removes listeners, aborts generators and releases displayed/retired geometries. Unpublished cancelled generator allocations have never entered WebGL and are GC-owned. Carry's fallback clones snapshot metadata because collider disposal empties its owned metadata array; borrowed coordinates/provenance are never detached or mutated. Independent review identified and verified this correction. Callback instance guards reject queued errors/results from terminated workers.

Visibility now uses worker-only asynchronous preparation on production interaction paths; readiness completion publishes an external-store epoch. Numeric geometry/material/transform signatures replace joined strings. A failed worker enters the exact cooperative collision fallback implemented by the haptics engineer, rather than rebuilding a BVH synchronously during hit admission. Existing synchronous creation remains available to explicit pure utility/test callers.
