## Outcome

U8 now accepts the exact typed Apple autoplay diagnostic vocabulary without
turning the diagnostic module, its file path, or autoplay-related product copy
into a broad exemption. The live U8 scan is green.

## Red before green

The initial static run reported two U8 findings in
`apps/web/src/apple-playback-diagnostics.ts`: the `autoplay-denied` diagnostic
class and the browser error phrase inspected by the classifier. These are
development diagnostics, not rendered product copy, but the content scanner had
no syntax context with which to distinguish them.

The same run also reported a credential-signature finding in a concurrent
D0-owned test. D5 did not edit that file or weaken the credential gate.

## Implementation decision

The authored-text representation now carries one syntax-derived U8 diagnostic
classification. It is true only when all relevant structural constraints hold:

- the source is the Apple playback diagnostic module;
- `autoplay-denied` is either a literal member of the named error-class type or
  a direct return from the named classifier function; or
- the browser error phrase is the sole argument of an `includes` predicate
  directly inside that classifier.

All other strings continue through the existing U8 matcher. No source path is
excluded from scanning, no line is skipped wholesale, and the production
diagnostic vocabulary was not renamed or removed.

## Completion correction

The exact `bun run gates` acceptance command originally invoked bare `bun test`,
so Bun's five-second per-test default could fail two legitimate Git-fixture
NAMING tests that take 8–11 seconds under a loaded shared workspace. The runner
now imports its command definitions from a side-effect-free module and invokes
`bun test --timeout 30000`.

The 30-second ceiling is still bounded. It gives roughly three times the observed
slow-test duration while leaving hangs and planted failures visible. A direct
runner-contract test locks both the numeric ceiling and the exact spawned
command, so removing or silently changing it is a deterministic regression.

- the browser error phrase used as ordinary prose rather than the classifier's

## Residual risk

The exception intentionally depends on stable diagnostic declaration and
function names. A future refactor that renames or restructures that typed
boundary will make U8 fail closed until the gate contract is consciously
updated. This is preferable to silently widening the exemption.
