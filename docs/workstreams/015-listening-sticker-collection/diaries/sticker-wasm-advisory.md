# Bounded WASM soft-body assessment — 2026-09-07

Recommendation: **Ammo at the exact commit already pinned by installed Three0.185.1 is a viable substrate for one bounded capability/performance experiment.** It is not an approved sticker implementation or a ready adhesive-film solver. Do not adopt Jolt for this experiment: its pinned5.6 documentation says soft bodies collide only with rigid bodies, leaving the required selfcontact implementation to us. The earlier slow JS whole-sheet solver does not establish how a native WASM collision/constraint loop will perform.

No source edits, dependency installations, engine executions or benchmark measurements were made for this assessment. Read-only upstream source was downloaded to /tmp. The canonical resource tree has no relevant Ammo/Bullet/Jolt checkout. Installed packages/device pins Three0.185.1; its AmmoPhysics.js explicitly references Ammo commit79190a1f03845794b1bba1777f30037349967658. All Ammo capability statements below refer to that exact commit, not the current Bullet feature list. Global Patterns was read for this architectural assessment; bun-only tooling and existing Jotai ownership remain.

## Exact evidence and limitations

| Need | Ammo evidence at the pinned commit | Consequence |
| --- | --- | --- |
| Original material mesh/stretch | CreateFromTriMesh, per-link material, node positions, rest lengths | Build once from the original planar rest mesh, then move node positions into an exterior seed without rebuilding rest lengths. Render the same topology/UVs. |
| Bending | generateBendingConstraints(distance,material) adds longer-range distance links | This is not a dihedral thin-shell law. A separate weaker bending material is possible; do not lock these links as extra inextensible diagonals. |
| Actual shell | btTriangleMesh and btBvhTriangleMeshShape bindings, soft-rigid world | Import only the approved actual exterior faces and explicit bridge geometry once. Do not replace the body with a box or convex hull. |
| Selfcontact | generateClusters plus native CL_SS and CL_SELF | There is an actual native path; vertex-face selfcollision is explicitly absent in this version. Cluster selfcollision is approximate, and connected clusters are skipped. |
| Contact hold/release | appendAnchor, mutable anchor array, per-node forces and inverse mass | Enough primitives for a product adhesion adapter; no surface-energy/contact-capture law is supplied. Friction is not adhesion. |
| Pointer anchor | Node inverse mass and position/velocity access | Pin the saved material center; preserve orientation with a small declared root constraint, avoiding all-sheet target pinning. |

The [pinned Ammo IDL](https://github.com/kripken/ammo.js/blob/79190a1f03845794b1bba1777f30037349967658/ammo.idl) exposes these bindings; [btSoftBody.h](https://github.com/kripken/ammo.js/blob/79190a1f03845794b1bba1777f30037349967658/bullet/src/BulletSoftBody/btSoftBody.h) defines the collision flags and material coefficients. [btSoftBody.cpp](https://github.com/kripken/ammo.js/blob/79190a1f03845794b1bba1777f30037349967658/bullet/src/BulletSoftBody/btSoftBody.cpp) implements selfcollision only when CL_SS is selected and CL_SELF is set; selecting the vertex-face mode does not enable selfcollision.

Important scaling traps found in that implementation: generateClusters allocates a C×C cluster-connectivity table, while generateBendingConstraints allocates an N×N unsigned adjacency table even in its optimized distance-two case. Therefore create these once, measure their retained/peak heap, and do not automatically create one cluster per triangle at high resolution. Native code is not a reason to ignore complexity. The clustered collision path also skips pairs sharing nodes, so exact connected-sheet intersection checks still matter near tight creases. These facts specifically limit the claim that this is an already solved full-triangle selfcontact runtime.

The [official Three r185 cloth example](https://github.com/mrdoob/three.js/blob/r185/examples/physics_ammo_cloth.html) uses the same Ammo pin, a20×15-cell cloth (336 vertices), ten position and ten velocity iterations, two arm anchors and live keyboard control. It copies solved node positions to the rendered mesh. Its [live demo](https://threejs.org/examples/physics_ammo_cloth) is a concrete integration example, not a measured benchmark for maximum C03, selfcolliding folds, or our216k-triangle assembly. The stock installed AmmoPhysics wrapper creates a rigid-only btDiscreteDynamicsWorld; use the soft-cloth example's btSoftRigidDynamicsWorld integration instead of assuming the wrapper supports cloth.

[Jolt5.6 architecture](https://github.com/jrouwe/JoltPhysics/blob/v5.6.0/Docs/Architecture.md#soft-body-work-in-progress) documents edge/dihedral/skin constraints and native soft-rigid simulation but explicitly excludes soft-to-soft collisions. Its [official JS soft-body demo](https://jrouwe.github.io/JoltPhysics.js/soft/soft_body.html) establishes browser cloth integration, not the missing selfcontact. Implementing another custom collision loop would defeat the purpose of this particular substitution, so do not pursue both engines in parallel.

## One bounded actual C03 experiment, before product integration

Use Ammo's pinned prebuilt WASM assets in an isolated diagnostic; do not install a wrapper or rebuild Bullet. The installed Three package contains the pinned loader reference but no bundled Ammo WASM assets were found. Obtain builds/ammo.wasm.js and builds/ammo.wasm.wasm from commit79190a1f03845794b1bba1777f30037349967658, store only in the task's diagnostic evidence/cache directory and record both SHA256 digests plus the exact URLs. This requires no package/lock change. Reuse the actual-source shell fixture and its provenance. A static triangle BVH owns copied CPU/WASM data and has exactly one lifetime. Keep approval status of actual seam/hold bridges explicit. A missing bridge must not become an invented solid cover just because an engine accepts triangles.

Use only the actual C03 angle0 center(157,268,3.1122703),115.5×228.32285 dimensions, with a33×33-vertex material mesh and one fixed configuration. The initial material positions are the rectangle's original u/v coordinates. Create structural edges from the actual indexed triangulation only, then distance-two bending links using a separate weaker material. Set structural m_kLST=1 and bending m_kLST=.05; these are empirical dimensionless test settings, not calibrated vinyl constants. Set gravity zero, restitution zero, kDF=.5, kDP=.05, pressure/volume/shape matching zero, piterations=10, viterations=10, citerations=4. Generate128 clusters with at most16 cluster-generation iterations; record the resulting count and its C² connectivity allocation. Select SDF_RS|CL_SS|CL_SELF (0x61), retaining soft-rigid contact with the actual triangle mesh rather than substituting cluster-convex support.

Use1modelunit=1engineunit. Declare soft collision margin .1modelunit and static mesh margin0; this is a numerical clearance assumption, not physical vinyl thickness. The intended self-separation is therefore approximately .2modelunit, but measure the actual triangles rather than inferring separation from margins. Total sheet mass1engine mass unit with per-vertex area weighting. The128-cluster choice is an experimental cap to expose quality/cost, not a proven sufficient collision resolution. Keep original rest UVs and center/orientation. Use the actual saved-center exterior normal and existing transported orthonormal angle-zero material frame to create an initial tangent-plane isometric sheet, with center offset .1 along that normal. Pin the central node and its two immediate positive-axis material neighbors in that same tangent frame for the duration of this static probe, making the small orientation anchor explicit. Validate the complete seed is exterior before stepping; failure stops the run. The largest unresolved dependency is the application load/contact-capture process: a freely hanging cloth demo does not make a tangent-plane sticker adhere around the back/front.

For this isolated static experiment only, use a declared pressing load followed by short-range adhesion. During physical time0–.5seconds, all unpinned vertices receive an attraction acceleration toward their approved exterior support plus .1normal offset: a=clampMagnitude(ω²(target-x)−2ωv,400), with ω=20/second. Apply force m*a, ramped linearly from0 to1 over the first .1seconds. This long-range force represents an external application press, not adhesive attraction. From .5–1second remove that force except for vertices within .25modelunit of verified support; for these maintain the same force law to model short-range tack. Re-evaluate contact admission each update, letting unsupported film lift and wrinkle. This first probe adds no distant pin anchors and no permanent contact capture. A sheet that falls away when the pressing load is removed fails adhesion; do not leave the load enabled to get a screenshot.

Use closestApprovedSupport and an exterior segment check against the existing source-backed support set to choose targets. Do not select hidden assembly bottoms or assign a front target through the body. Determine targets outside the native iteration loop; permit at most one exact refresh per unpinned node per native step and report its separate time. Cached support must retain exact-query semantics and invalidate on facet/bridge changes. This may still be too expensive, which the timing must show; no speed claim depends on hiding JS support time. This explicit force adapter is remaining product work, not a built-in Ammo feature or a calibrated vinyl law. No local adhesion profile tuning is part of this run.

Run exactly120steps at1/120second, calling stepSimulation with maxSubSteps0 so the supplied fixed timestep is explicit. Repeat from the identical initial state for240steps at1/240second, the same one-second load schedule and the same iteration counts; this is the only convergence comparison. Do not vary stiffness, cluster count, margin or load when the first run fails. Abort either run at two seconds of measured solver-plus-support CPU, reporting the partial physical time and failed runtime cap. Record cold WASM initialization/BVH/constraint construction separately, warm per-step native time, exact-support time, node-copy time, final buffer/render cost and peak/retained WASM memory. No65-grid expansion until an independent decision after these outputs.

Report full UV singular values, occupied-print metrics, every-triangle shell and selfintersections including opposite-edge crossings, gap distribution/footprint, C03 rear/oblique/side/front glyph views and remaining velocity. Compare .5second pressing-end and1second tack-only states. The existing accepted strip's measured .956–1.153 envelope is a comparison target, not a new material specification; no collapsed/inverted cell is allowed anywhere. A fold that never selfcontacts does not prove the cluster selfcontact capability, and adjacent-cluster exclusions remain an explicit gap. Failure to adhere is a failed experiment even if native simulation is fast. Native flags never replace exact checks on the mesh positions actually rendered.

Cleanup is part of the diagnostic: remove the soft and static bodies from their world, destroy the body/shape/mesh/solver/world/configuration objects in ownership-safe order, release all temporary vectors/transforms/arrays and WASM heap buffers, and dispose only renderer resources created by this probe. Do not dispose borrowed production geometry. Maintain a creation ledger to verify matching explicit destruction; distinguish Emscripten heap capacity remaining reserved from live native objects. No retained callback, render loop, world or old output buffer after the probe.

Production consideration requires the current/previous pose and a warm incremental update to follow direct input without visible delayed settling. A20ms native step cannot be hidden by a worker; end-to-end input-to-presented geometry and matching render/hit/contour generations would be later gates. No UI/worker infrastructure is authorized by this static experiment. Loading a dependency, demonstrating falling cloth, or achieving low total energy does not close corner wrapping or gesture performance.

## Decision boundary

Ammo clears the basic capability gate better than Jolt because native selfcollision is present and exposed. It does **not** supply guaranteed continuous triangle contact, calibrated adhesive film, or a ready instantaneous arbitrary-placement embedding. The narrowly useful next action is exactly this actual C03 substrate probe with its fixed half-step comparison. The evidence does not justify declaring either that WASM will solve the task or that existing engine runtimes cannot solve it.
