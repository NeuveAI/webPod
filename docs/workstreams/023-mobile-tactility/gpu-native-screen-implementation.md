The four-module CPU021 surface is frozen: device/native-element-image.ts plus composite/native-screen-transport.ts, panel-projection.ts and html-in-canvas.ts. One capture credit owns one transferred snapshot. Generation stamps include renderer/capture/layout/raster/visibility/paint identity. Exact consumption acknowledgement releases credit; stale acknowledgements do not. Missing acknowledgement for15seconds retires the entire host generation through its failure callback, without overlapping recapture. Hidden/disposed transports stop capture; disposal clears their watchdog.
