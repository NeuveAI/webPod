# Thumb opposition — drawings inspected directly

Owner correction: the thumb rotates at its base toward the index while the index
flexes at its base and middle joints. Do not infer this motion merely by optimizing
tip proximity or the opening's silhouette.

## Flexion versus opposition

[eOrthopod / Medical Multimedia Group drawing](https://eorthopod.com/images/ContentImages/Fractures/adult_fractures/adult_hand_fx/adult_finger_fx_thumb_flex_opp.jpg)

Inspected the actual 400×400 drawing in the browser, including its arrows and
labels. Its two panels distinguish thumb CMC flexion from opposition, which adds
rotation. Applied observation: the thumb pad changes orientation as the base
turns; translation toward a target alone does not describe the gesture. The drawing
is a movement reference, not the final index-pinch pose. Copyright shown: MMG.

## Base articulation

[Saddle-joint drawing hosted by Orthobullets](https://upload.orthobullets.com/topic/6036/images/saddle_shaped_joint.jpg)

[Hosting anatomy context](https://www.orthobullets.com/hand/6036/base-of-thumb-fractures)

Inspected the actual 555×384 drawing in the browser. It labels medial rotation
with flexion, lateral rotation with extension, and roll/slide at the trapezium–first
metacarpal articulation. Applied observation: the movement originates at the thumb
metacarpal base, carrying the phalanges with it. A simple fixed-axis finger curl
does not represent this base articulation. This is a hosted reference illustration;
no authorship or license to redistribute is assumed.

- `thumb.01.L`: first metacarpal; its proximal pivot represents the thumb CMC base.
- `thumb.02.L`: proximal phalanx, bending at the thumb MCP joint.
- `thumb.03.L`: distal phalanx, bending at the thumb IP joint.
- `f_index.01.L`: proximal phalanx; index base/MCP flexion.
- `f_index.02.L`: middle phalanx; PIP flexion.

The next pose pass must explicitly show the thumb base turning the pad toward the
index, coordinated with positive index MCP/PIP flexion toward the palm. Keep PIP/DIP
lateral rotation absent. Show the base and pad orientation markers through the
