## Owned files and behavior

Exact nine-source-plus-test manifest under evidence/gpu-worker/visible-contour/integration/manifest.json. Source ownership: device sticker-projection.ts/sticker-contract.ts/StickerPackScene.tsx; composite device-render-host.ts/native-sticker-controller.ts; app production-device-view.tsx/sticker-editor.tsx/sticker-editor-model.ts/new sticker-contour-query-model.ts. Existing app sticker-editor-carry.test.tsx adapted to the async facade, plus focused capture proof. No host panel-dimension optimization or C1 owner/worker edit.

StickerRearProjection exposes optional contourQuery presentation interface. Shared createStickerProjection owns one C1 query authority and captures only actual mounted equipped/carried mesh, validated PhaseB descriptor, existing prepared contour and9 private live samples. Borrowed visibility snapshot goes to C1's private-copy/reservation boundary without transfer; world/camera/content/rectangle are copied coherently. Missing/invalid metadata, unready collider or invalid viewport clears presentation and never falls back to synchronous contour tracing. Existing synchronous contour method remains for legacy noneditor consumers/parity; the editor no longer calls it.

Native controller reads exact admitted binding pose through the host. GL uses the lead-approved discriminated capture stamp: sequence per coherent query capture, layoutRevision when rectangle/projection changes, sceneRevision from actual visibility revision and resourceRevision from geometry weak identity. It does not invent native motionEpoch or command sequence. GL projection lifetime now depends only on scene/camera/canvas and callback identity, with dynamic scene via existing ref. Existing R3F useFrame refreshes active query demand without an additional RAF loop; C1 geometrically deduplicates unchanged captures. Inactive demand returns immediately. Dynamic notifications and viewport/current geometry remain live.

The app Jotai bridge stores stamped query state, attaches to the currently published projection and schedules updates in a microtask outside renderer commits. Replaced-owner subscriptions/publications are invalidated. Existing coalesced projection notifications refresh demand outside React render. Inventory placement changes invalidate previous presentation before recapture; compatibility for ordinary adopted preview updates remains C1-owned.

The editor submits demand from committed layout effects and renders subscribed exact results. Ordinary projection updates do not have cancellation cleanup. Human positive fade retains its selection session; fully hidden/unmounted stops demand. New explicit query-session atom advances every human select, including same-ID reopen, independently of existing async write lifetime. Tool sessions use their computation epoch in a disjoint odd-numbered session space; human sessions are even. UI checks session+sticker ID before rendering a result, preventing a late previous selection from appearing during effect turnover. Source-role/layout/collider/backend hard barriers stay in C1/capture. Document hide clears query immediately, resume captures fresh state. Current beginTransform pointer authority, drag validation and inert human-fade/tool DOM remain unchanged.

A latched query error exposes a recoverable controls message with Retry alongside any retained valid sampled controls, preserving input and authored fade/tool inertness; retry clears the failed query generation and requests current shown selection. There is no silent main-thread full-sweep fallback or automatic worker retry loop.
