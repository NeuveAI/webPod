## Conservative certificate, including joins

Both original and candidate cap are single-valued piecewise-linear height graphs over the same XY domain. Overlay each candidate triangle with the original cap triangles whose XY boxes overlap; clip their projected triangles to obtain overlap polygons. At every overlap polygon vertex compute both barycentric heights. Their difference is affine within that polygon, so its extrema occur at those vertices. This is an exact finite certificate for the meshes being compared, subject to an explicit robust numerical tolerance, rather than vertex-only nearest-distance sampling.

First measure the raw lower/upper signed errors. To create a conservative outer envelope without changing the actual aperture or bevel boundary, allow an upward correction only on unprotected candidate vertices. Let w(x,y) be the sum of barycentric weights belonging to those free vertices in a candidate triangle. For each overlay vertex p require delta*w(p)≥zOriginal(p)−zCandidate(p). Choose the smallest nonnegative global delta satisfying these inequalities. If w=0 but the right side is positive beyond tolerance, the declared mesh cannot be corrected while preserving its boundary; fail the certificate rather than moving that boundary. The original protected-band vertices remain fixed.

Apply that delta to the free candidate vertex heights, then rerun the complete overlay certificate. Require0≤zLOD−zOriginal≤.05unit everywhere, allowing only an explicitly reported ≤1e-5 numerical tolerance. Both heights use the same XY coordinate, so this also yields a two-way Euclidean Hausdorff bound≤.05unit. The sign establishes that the cap proxy encloses the original cap on its exterior+Z side. Ordinary cap/bevel and aperture joins remain exact because their entire protected band is unchanged. This changes only the collision approximation; it does not add hover/slack to the sticker embedding or replace a real aperture with a cover.

If the required lift or final maximum gap exceeds.05, stop this12-unit candidate. Do not widen the error budget, increase native margin, introduce boundary skirts or replace holes. The independent native sheet-versus-original-shell oracle remains mandatory even after this certificate: neither a conservative proxy nor Bullet's cluster flags guarantee a collision-free solved sheet.

For orientation, the source sixth-order crown has |profile''|≤56/3 on[-1,1]. With1.2amplitudes and half extents163.8/274.8, the separable interpolation bound Mx*hx²/8+My*hy²/8 is about.0204unit for a12×12cell, versus.0023for the original4×4cell. This is a useful a priori scale check, not a substitute for the mesh overlay certificate, particularly at clipped source-triangle and protected-band boundaries. Form changes, nonzero edge crowns or different source hashes require a fresh certificate.
