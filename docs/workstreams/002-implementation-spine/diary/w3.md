# W3 diary — Panel DOM

Implemented the 272×204 panel as semantic React DOM, deliberately independent of the device renderer and HTML-in-canvas integration. S03, S08, and S13 share the singleton `deviceStore`, use the Apple-shaped fixture provider, and are keyboard navigable (arrows, Enter, Backspace/Escape). Both explicit colourways render together at `/`.

The implementation includes all eight prescribed states, the three-stop S13 centre cycle, fixed 21px title geometry, eight 26px loading rows, sharp-artwork clamping, list virtualization beyond 100 rows, one live region, preference media queries, and no component-local state.

Visual work was compared through Pencil MCP against `A76Ib`, `DLqSo`, `H4QpB`, then the reusable S03/S13 nodes `HYNXu` and `mObBW`. Evidence includes paired overviews and tightly cropped integer-scaled panels with no page chrome.

Owner-only gates remain open: U14 thumb-occlusion validation and H-6 aesthetic acceptance in both colourways. This lane does not claim either passed.
