## Data and behavior invariants
Genre sheet grouping derives from inventory; mixed starter grant can populate several sheets. Only collections with at least one owned sticker are accessible. Five slots are canonical catalogue order. Starter-owned tier is earned at zero measured minutes. Locked slots remain focusable/readable but cannot start peel; unopened owned prints remain sealed until the relevant real grant is opened. Placement leaves an unprinted die-cut seat and can be returned via semantic action. Future printed art is monochrome, distinct from empty placed seats. Milestone display [5,15,60,180,600] is tested against actual v1 server policy; presentation does not grant anything.

One pixel layout contract positions DOM seats and R3F plane in camera space. Wide screen places liner to right of device; narrow screen holds it low. Camera and actual rear mesh still resolve drop coordinates. Direct peel uses radial travel: partial contact stays anchored through64px release travel, then a continuous catch-up preserves pointer attachment; reduced motion follows directly. This replaces the old100px-up-only dead zone. Pointerup samples final coordinates. Pointer-drag click is suppressed so a trailing click cannot supersede a pending save. Release retains bounded inertia, cancellation returns to sheet, stale async callbacks retain generation protection.

All render art uses approved immutable RGBA, same alpha threshold and studio physical clearcoat. Liner has depth and curl; the separate folded paper sleeve has a thumb notch and glued folds. Initial crimp ridges were removed as incoherent with paper construction. Curls retain UV and show unprinted adhesive backside. Shared animation owner animates sheet reveal using existing spring, reduced-motion snaps. No second canvas, render loop or shadow scheduler.
