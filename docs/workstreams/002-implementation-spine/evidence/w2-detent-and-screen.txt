W2.2 / W2.3 — the detent reducer and the screen state machine
==============================================================

001 §4.4's four input paths plus the programmatic seam, and 001 §4.2's menu
hierarchy with push/pop and a highlight index.

The rule that dominates: arrow keys are exactly one detent, always, with no
acceleration, ever. Counted navigation is how P5 drives this device, and the
test that guards it drives 40 keydowns 5ms apart — far faster than any human
or any OS auto-repeat, and far over every arc acceleration threshold — and
asserts the highlight moved exactly 40 rows.

Acceleration exists on the two arc paths only. The scroll path has no velocity
multiplier at all, because trackpad momentum already supplies one.
