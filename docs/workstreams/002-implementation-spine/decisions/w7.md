# Decisions — W7 click-wheel runtime

## W7-D1 · A wheel burst ends 120ms after its latest event

Wheel events have no native terminal event. The runtime therefore treats them
as one gesture and resets a single injected timer after every event. The binding
idle interval is **120ms**. Expiry calls `endGestureActionAtom` once and never
starts coast. This is independently literal-gated; tests do not derive their
expectation from the exported constant.

## W7-D2 · Composite owns the focus contract

Blink's pointer path focuses the canvas. The composite boundary is the first
layer that sees both the real DOM panel and the R3F annulus, so it remembers the
focused descendant with `role="application"` and restores it after arc release
or cancellation. It also queues restoration at start to cover the pointerdown
default action. Device remains geometry/capture-only and Panel remains keyboard-
semantic-only.

## W7-D3 · Production behavior needs a mounted production gate

Injected runtime tests prove the state machine but cannot prove React effects or
the callbacks passed to the device surface. `CompositeInputBoundary` is the
production owner and is mounted in Happy DOM with the singleton store. Replacing
its three callback forwards with no-ops must fail on actual highlight movement.

## W7-D4 · Browser evidence is tied to bytes, not a running tab

The browser runner starts a fresh Vite process and fresh Chrome profile with the
feature flag, fingerprints all Vite-served application/package bytes before and
after, and records both digests. A changed digest invalidates the run.
