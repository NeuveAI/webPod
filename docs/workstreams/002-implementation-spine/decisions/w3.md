## Decisions

1. `deviceStore` is the sole store. The route mounts two Providers over that same store so the colourways remain synchronized and tool callbacks observe the rendered state.
2. Panel internals remain exactly 272×204. The owner preview uses integer page zoom; Dynamic Type scales only the bounded panel stage and is capped at 1.25.
3. Unsupported capabilities are absent from the model, never disabled controls. Radio is therefore absent from S03 under the launch matrix.
4. S08 uses ordinary semantic rows for the fixture and a deterministic eight-row window after 100 rows. Loading remains exactly eight 26px rows. This avoids an app-level dependency mutation outside W3 ownership while bounding the rendered DOM.
5. The route imports the owned package source directly because W3 was not authorized to mutate the shared app manifest. The package remains exported normally as `@webpod/panel` for consumers that declare it.
6. HTML-in-canvas, device materials, and composite transforms are outside this package. The panel is independently focusable semantic DOM.
7. H-6 and U14 require owner observation and remain explicitly open.
