- D005-01: The latest owner instruction removes the standard Now Playing queue
  count. It overrides the queue-count photo and workstream 004.
- D005-02: Exact six-second Apple Music byte buffering is not representable through
  the public provider surface. Safe public preparation and measured latency are the
  acceptance substitute; no private media or DRM path may be invented.
- D005-03: Dark mode has palette latitude only; it is not permission to change the
  period geometry or introduce modern UI idioms.
- D005-04: The current SFX implementation is procedural. HTTP audio preload tags are
  required only if real static audio assets become the production source.
- D005-05: Neuve shell commands are intentionally not used because repository law
  explicitly says no Neuve shell exists in this project.
- D005-06: The eight-row requirement applies at the production 100% Dynamic Type
  setting and under visual/camera scaling. An explicit accessibility Dynamic Type
  override may show fewer rows to avoid overlap; it must preserve the rail and all
  interaction semantics.
- D005-07: The owner rejects the first pending-playback stripe implementation as
  unlike the supplied Aqua reference. The supplied Aqua raster and
  `aqua-loading-criteria.md` override the current CSS, its tests, and generic
  no-gradient advice. Final acceptance remains an owner visual decision after PM
  and independent review; automation cannot waive it.

  MusicKit's queue-ready and pre-audible interval. A matching item, resolved play
  command, or coarse `playing` label is insufficient; forward movement of the
  selected item's public playback clock is the successful dismissal boundary.
- D005-09: The latest owner direction supersedes the previously accepted `236x5`
  loading/progress geometry. Both states now use the taller shared geometry in
  `research/playback-bars-quadrants-pm.md`; previous approval remains historical.
- D005-10: “Whole quadrant” means four complete 90-degree annular tap sectors, not
  label-centered disks and not sectors with diagonal dead gaps. Movement beyond
  slop still cancels the tap candidate and becomes wheel rotation.
- D005-11: The photographed volume presentation is a transient replacement for the
  progress/time band. A 1500ms post-input dwell is the reversible default; final
  visual weight and timing require owner observation.
- D005-12: The owner rejects the 9px progress/loading versus 14px volume split and
  the flat three-stop Aqua fill. Progress, loading, and volume must share a 14px
  outer / 12px inner height and one cylindrical pale-top/dark-waist/pale-bottom
  material; loading ribs inherit that lighting, and a hard bottom-colored row is
  forbidden. The latest attached Aqua specimen and corrected PM memo supersede the
  prior candidate, tests, evidence, and reviews on this visual point.
- D005-13: The owner rejects the corrected candidate's uniform gray frame. A
  border-only surround is not Aqua: the accepted trough requires separate exterior
  cast shadow, asymmetric molded lip, dark inner seam, concave empty channel, and
  rounded corner masks. The latest cropped screenshot is the rejected candidate;
  the full Aqua specimen remains the positive source.
