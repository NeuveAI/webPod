# Source-bound wrapped pickup witnesses

The four proof JSON files and manifest target immutable cold-inverse-matrix-1. They are generated from exact actual C03 position/UV/index buffer SHA256 matches, captured model/view/projection matrices, and original PNG alpha with deterministic wear1 erosion. The actual FrontSide ink draw is identified by enabled BACK culling and CCW front-face state; the backing draw shares geometry but reverses front-face state. Each required rear/front/glass source geometry is correlated by actual same-pass position-buffer FNV1a/byte length and model matrix, with source SHA256 recorded separately. FNV is a correlation fingerprint, not a cryptographic GPU-buffer hash.

The finalizer rejects stale sampler/grab source hashes, stale build/artifact aggregate identities, missing source shell draws, and unsolved admitted path samples. All15/17/8/14 admitted calls solve with the current helper. The12px partial samples are explicitly unadmitted, matching production's64px detach threshold. Returned placements are accepted only by the exact shown-UV residual; the plane guess is not an accepted placement.

Selected rays lie on source rear/front/glass regions away from hardware apertures. This offline fixture does not reconstruct all hardware; the actual native production visibility collider uses the full rendered assembly and remains authoritative. Occluded points are also backfacing, so native refusal alone does not isolate occlusion-BVH rejection from FrontSide culling. Separate visibility tests cover frontfacing blocked segments.

These are geometric interaction prerequisites, not native contact/landing/performance acceptance. The native run must use recorder-off mode and the exact manifest, then independently inspect attached-source and partial-peel originals. Script and proof hashes are in proof-sha256.json; original art provenance is separate. Reproduction: run generate.ts with absolute capture-directory and output-directory arguments, then finalize.ts with the output directory. Both require unchanged source matching the immutable build.
