# Sticker HUD geometry

2026-09-06. Read the replacement scope and approved design brief. The previous axis-aligned rectangle cannot describe rotated artwork or perspective. The new helper samples the actual conformed mesh by its UV coordinates, returning artwork-ordered TL/TR/BR/BL corners, four edge midpoint vertices and center. It does not substitute a screen-aligned box or regenerate art.

`sticker-transform-projection.ts` exports `stickerProjectedQuad(print, camera, canvas)` and `captureStickerTransformPlane(content, camera, canvas, localDepth)`. The optional device projection methods are `quad(placement)` and `beginTransform(placement)`. The app engineer owns scene integration and all handle interaction. Existing wear, geometry, materials and persistence are unchanged.

The inverse captures camera projection, camera world, content world and canvas coordinates once. It intersects the unprojected ray with the selected center's local depth plane, then converts to rear coordinates with the actual body width and height. It remains usable outside the physical mesh where outboard touch handles live. This is an editing plane, not an exact inverse of a curved shoulder. The caller must preserve the original pointer offset, reject zero-radius gestures, and cancel on viewport/device/camera changes. Clockwise angle calculations require physical width/height units rather than normalized coordinates. No helper owns animation frames, subscriptions or GPU resources.

## Browser-discovered DOMRect correction

The first native rotation found a non-null captured plane whose project method returned null, so no write occurred. The helper had spread `getBoundingClientRect()` into a plain object, incorrectly assuming its dimension fields were enumerable own properties. Browser DOMRect exposes them through prototype getters. The original plain-object unit fixtures did not represent that boundary; their pass did not establish browser compatibility.

The correction copies left/top/width/height explicitly and validates those same explicit fields rather than Object.values. A prototype-getter regression proves coordinate roundtrip, frozen values after the original rectangle changes, and rejection of an infinite getter value for both capture and quad projection. The updated targeted suite passes six tests and 46 assertions; device typecheck and scoped helper/test lint pass. The UI owner must rerun actual rotation after rebuilding; no browser pass is claimed here.
