W2 — every commit typechecks standalone
=======================================

Each commit is extracted from git into a clean directory (`git archive`), given
only the shared tsconfig base and a symlink to the installed dependencies, and
typechecked on its own. No working-tree file leaks in, so a commit that only
compiles because of a later commit's file fails here.

$ cd <archive of 5f92872> && bunx tsc --noEmit -p packages/state/tsconfig.json
  5f92872 feat(state): store contract
  exit: 0  clean

$ cd <archive of 1bbe51d> && bunx tsc --noEmit -p packages/state/tsconfig.json
  1bbe51d feat(state): detent reducer
  exit: 0  clean
