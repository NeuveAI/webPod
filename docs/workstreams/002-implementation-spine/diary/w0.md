## What I want a second opinion on

**One ruling wanted, one flag, one loose end.** Detail is in `decisions/w0.md`.

1. **RULING WANTED — Tailwind v4 tree-shakes `@theme`.** §12.1 declares the FX geometry,
   durations, easings and panel dimensions inside `@theme` and comments that they are
   "consumed by JS/SVG, exported here as one source of truth". They are not: measured on
   the real build, `--fx-wheel-r`, `--fx-halo-blur`, `--panel-w`, `--dur-tick`,
   `--ease-agent` and the rest are absent from the stylesheet, because v4 only emits an
   `@theme` variable that some generated utility uses. The one-word fix is
   `@theme static`. I did not take it, because the packet says transcribe §12.1 exactly,
   and `globals.css` is provably byte-identical. The typed TS export covers JS consumers;
   only CSS-side `var()` references are affected, which is W3/W4 territory.
   Measurement: `evidence/w0-theme-treeshake-finding.txt`.

2. **FLAG — §7.3's desktop geometry column is stale** against §12.0 and I deliberately did
   not export it. §12.0 re-derives the mobile column only; carrying its 0.697 correction
   to desktop would imply `wheelR` ≈ 136, which nothing in 001 sanctions. Whoever owns
   desktop layout needs that re-derived in 001 rather than guessed here.

3. **LOOSE END — the `.gitignore` security fix is uncommitted.** The lead edited it
   mid-slice to cover `cert/`, `*.p8`, `*.pem`, `*.key`, `*.p12`, after a MusicKit signing
   key turned up untracked but *not* ignored — one `git add -A` from a shared GitHub repo.
   I verified the block works and left it out of my three commits, per the
   commit-boundary guard. It protects this working tree only until it is committed.
   I did not read or copy any key material.

Also worth knowing: `/global-patterns` and `/bun-http` both point at
`~/code/agent-context/`, which does not exist (the clones are at `agentic-context`, and
carry no such files), and `/shadcn` shells out to `npx`, which this repo forbids and this
machine lacks. All three are broken for every agent on this repo, not just me. I grounded
in the clones directly instead.

## Handover notes for the lanes that come next

- **The typecheck loop needs no maintenance.** `scripts/typecheck.ts` discovers any
  directory under `apps/` or `packages/` that has a `tsconfig.json`. Add a package and it
  is covered; there is no list to update.
- **Add dependencies to your own package's `package.json`.** Bun 1.4's isolated linker
  gives each workspace its own `node_modules`, so nothing is hoisted and nothing collides.
  The skeletons deliberately ship with zero dependencies.
- **`bun run gates` exits 1 by design** until W5a implements it. Do not "fix" it by making
  it exit 0.
- **The route tree is generated and committed** at `apps/web/src/routeTree.gen.ts`. The
  Start plugin rewrites it on `dev` and `build`; commit the result rather than gitignoring
  it, or a cold `bun run typecheck` fails.
- **`useState` is a lint error**, including the `React.useState` and import forms.
- **Consume geometry from `@webpod/tokens` as TS**, not from CSS custom properties — see
  the ruling above.
