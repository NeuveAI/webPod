`sticker-alpha.ts` shares image alpha extraction, a deterministic edge damage field and a derived threshold texture. Full source alpha is read once before gesture admission. The damage field's longest dimension is capped at256 texels, with distance to transparent edges and seeded uneven shallow nicks/deeper bites. Wear monotonically crosses fixed byte thresholds; changing wear never regenerates a texture or random seed. The original PNG is untouched. Zero removes runtime edge damage but cannot erase baked artwork distress. Front and adhesive back use the same mask threshold; the back remains unprinted. CPU hit testing samples original alpha plus the same nearest damage threshold. No cast-shadow mesh existed on these print meshes, so there is no separate stale rectangular shadow to update.

Derived threshold bytes are copied once into explicit bottom-up UV row order, with flipY=false, nearest filtering, no mipmaps and non-color RedFormat. The source texture's dispose event releases the derived texture and cache once; borrowed maps/materials and preparation clones never dispose it. Repeated source disposal is harmless, and a retried source prepares a fresh resource. Tests cover sharing, explicit row mapping, disposal, retry, identity mismatch and one readback per source lifetime.

`sticker-contour.ts` traces occupied texel boundaries, preserving disconnected paths and hole winding. It removes only collinear vertices: no convex hull, bounding rectangle or rounded rectangle approximation. A four-entry LRU per field caches topology by wear byte, so rotating merely projects cached boundary points and small continuous wear deltas within a threshold reuse topology. Projection interpolates the actual triangles of the production24-segment conformed mesh, then applies current world/camera matrices. External loops alone supply corner-sector anchors; inner cutouts cannot host grips.

The boundary sampling resolution is a stated approximation: at100px across the entire texture, one256-grid texel is approximately0.39px; visible artwork padding and larger projected prints increase this error. There is no additional curve simplification error. Normal-size and maximum-size actual renders must verify that this does not appear stepped or misaligned. The raw-alpha hit boundary retains original source resolution; shared erosion threshold addressing is exact, while the extracted original alpha contour is sampled at the bounded resolution. Do not describe those original boundaries as mathematically pixel-identical at arbitrary zoom.

Wear scratches now have deterministic per-cell orientations and bounded segment lengths instead of repeated parallel stripe directions. Existing ink abrasion, roughness and clearcoat response remain. Front/back variant keys are stable at all wear values; mutable uniforms update without shader recompilation. Underlying geometry and peel kinematics are unchanged.
